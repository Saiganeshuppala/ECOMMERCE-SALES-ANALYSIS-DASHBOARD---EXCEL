* E-Commerce Sales Analysis Dashboard (Excel) *

This repository contains a professional Excel-based dashboard for analyzing large-scale e-commerce sales data. It provides a clear, interactive, and insightful overview of business performance using key sales metrics and visualizations.

** Features  **

- *Interactive Dashboard*: Filter and view data dynamically using slicers and dropdowns.
- *Data Cleaning*: Pre-processed using Power Query to remove duplicates, handle missing values, and normalize data.
  
- *Key Metrics Tracked*:
  - Total Sales & Profit
  - Monthly orders
  - Top Products & Categories
  - Sales Distribution
    
- *Visualizations*:
  - Bar and Line Charts
  - Pie charts
  - Heatmaps
  - KPI Cards
    
- *Optimized for Large Datasets*: Capable of analyzing over 10,000 rows of sales records.

## Dataset

- *Source*:  KAGGLE
- *Columns*: Order Date, Product, Profit margin, Sales, Quantity, Profit, Region, Segment, etc.
- *Size*:    10,000+ rows

## Tools Used

- Microsoft Excel
  - Power Query
  - Pivot Tables & Pivot Charts
  - Conditional Formatting
  - Slicers & Timeline Filters
